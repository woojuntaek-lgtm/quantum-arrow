# 양자 화살표 놀이터

양자 상태를 **길이 1짜리 화살표**로 보고, 손가락으로 끌어 **그림자의 제곱 = 확률**(보른 규칙)을 직접 확인하는 체험 앱입니다. 측정 축 고르기, 한 번/100번 측정, 상대 위상과 전체 위상의 차이까지 한 화면에서 만져 볼 수 있습니다. 「수학자의 양자역학」 강의 부록이며, 파일 하나(`index.html`)로 인터넷 없이 동작합니다.

> **바로 하기: https://woojuntaek-lgtm.github.io/quantum-arrow/**

## 특징
- 화살표 끌기 → 동·북 그림자와 확률 실시간 표시 (3-4-5 예시 자동 맞춤)
- 측정 축: 동·북 / 대각선 / 직접 돌리기
- 한 번 측정(화살표가 한 방향으로 떨어짐, 같은 축 재측정 시 100%) · 100번 측정(이론값과 비교)
- 위상 다이얼: 상대 위상은 대각선 축에서만 드러나고, 전체 위상은 어떤 측정에도 영향이 없음을 확인
- 5문항 퀴즈(10문항 중 무작위)와 쉬운 원리 설명
